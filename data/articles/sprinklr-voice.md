# Sprinklr Voice

#
Sprinklr Voice


	Sprinklr IVR offers a powerful feature that allows brands to provide their customers with the ability to schedule, update, and cancel using APIs. This feature comes in handy when customers face extended wait times or need assistance during off-hours. The flow to accomplish this via APIs is as follows:
​
- **Fetch Work Queue Stats**: Using this API, you can fetch the work queue stats for the given work queue id.

- **Fetch Time Slots**: Using this API, you can fetch the available time slots for scheduling the callback

- **Schedule Callback**: Using this API, you can schedule a callback by passing the available slot details derived from the Fetch Time Slots API

- **Update Callback**: Using this API, you can update the details of a scheduled callback

- **Cancel callback**: Using this API, a scheduled callback can be cancelled
