# Reporting v1

#
  Reporting

Sprinklr Reporting Insights stores and visualizes data for all digital channels  and provides actionable insights for posts and accounts. Reporting promotes informed-decision making and helps drive revenues.

In Reporting, you can customize, expand, and drill into metrics to discover what's working and what’s not, and develop data-based strategies to continuously improve your content performance. With reporting you can access the most relevant data to your social performance, which ,in turn, promotes informed-decision making.

To ensure that new users in your Sprinklr environment are set up with the appropriate access and capabilities to access and view Reporting, you'll want to ensure that their role is granted the right permissions.

For instance, for making API calls using reporting dashboards, the user should create a role for [Generate Widget API Payload](https://www.sprinklr.com/help/articles/integration-guides/generate-api-v2-payload/633c5ca8a0522e093b06c1a2) for generating API request payloads through the UI.
