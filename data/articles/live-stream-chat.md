# Live Stream Chat

#
  Live Stream Chat


	You can pair your live video or product launches with stream chat for a real-time messaging experience for your customers. Once the live stream event starts, you can view the users' messages in real time.

With live stream event APIs, you can create a live chat session for a live stream event. Once created, you can fetch the live chat event/s, start or end an event, and also update the event using the respective APIs available in this section.

**Related Knowledge Base Article:** **[Getting started with livechat commerce](https://www.sprinklr.com/help/articles/introduction-to-livechat-commerce/getting-started-with-livechat-commerce/6780e9d02136755ad71c56c7)**

### Live Stream Chat APIs


-
    [Create/Update Live Chat Event](https://dev.sprinklr.com/create-update-live-chat-event): Using this API, you can create or update a live chat event for sending or receiving messages.


-
    [Fetch Live Stream Chat Events](https://dev.sprinklr.com/fetch-live-stream-chat-events): Using this API, you can fetch multiple live stream chat events for the given live chat stream Ids.


-
    [Fetch Live Stream Chat Event](https://dev.sprinklr.com/fetch-live-stream-chat-event): Using this API, you can fetch a single chat event for the given live chat stream Id.


-
    [Start Live Stream Chat Event](https://dev.sprinklr.com/start-live-stream-chat-event): Using this API, you can start an event instantly for the given live chat stream Id.


-
    [End Live Stream Chat Event](https://dev.sprinklr.com/end-live-stream-chat-event): Using this API, you can end an event instantly for the given live chat stream Id.
