# Custom Field

Custom Fields are fully customizable properties or tags that can be created at several feature levels (for various assets), which allow you to organize and categorize content.

### Supported Custom Field Types

- **Picklist Multiselect**: You can select more than one value from the available options while applying this type of Custom Field.

- **Picklist**: You can select only one value from the available options while applying this type of Custom Field.

- **Number**: The value will be in numerical form. Use this field type to add a phone number, employee ID, etc.

- **Date**: A calendar will pop up while applying a date type custom field, for example, purchase date, complaint date, completion date, etc.

- **Text Multi**: This is like a multipicklist, but you do not define any values when you create this custom field. You can create options on the go when using it for any asset.

- **Text Area**: This is the same as text but can hold more length than text.

- **Text**: This field allows you to add text details, i.e. Name, Customer ID, Description, etc.
