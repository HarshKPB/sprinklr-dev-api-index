# Data Ingestion

 

Sprinklr allows importing profiles and messages in bulk using excel files. With Sprinklr's Import data feature, adding your data from an excel file becomes swift and intuitive.

This enables you to leverage the power of Sprinklr AI, listening and automation on the external data imported into Sprinklr using the Data ingestion API. You can visualize the external data alongside Sprinklr data in the same unified dashboards.

### Data Ingestion APIs

- [Import Bulk Profiles](https://dev.sprinklr.com/bulk-profile): Using this API, you can download the excel template and import profiles in bulk

- [Import Bulk Messages](https://dev.sprinklr.com/bulk-messages): Using this API, you can download the excel template and import messages in bulk
