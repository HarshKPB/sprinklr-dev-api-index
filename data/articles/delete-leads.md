# Delete Leads

#
  POST Delete Leads




The Delete Lead API allows authorized callers to remove an ingested lead from the system for correction or compliance purposes, requiring only the lead ID which can be obtained through the Search Lead API to perform the deletion. The API also supports bulk deletion, returning only the IDs of leads successfully deleted while omitting those that were not found, ensuring clean handling of mixed validity requests.

**Dev Notes: **No special permissions are required, and when a valid lead ID is provided, the API permanently deletes the record, logs the action for audit purposes, and returns a 204-style empty response; if the lead does not exist, the response remains blank.

## API Endpoint

https://api3.sprinklr.com/{env}/api/v2/dmp/delete-lead
