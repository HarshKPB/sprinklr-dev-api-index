# API2.0

#
        API 2.0


Sprinklr API v2.0 is the latest version of APIs launched in late 2019 and is built on standard business objects like Message, Case, Profile, Task, etc., similar to webhooks.

API 2.0 is more robust, lightweight, and faster. We have also started to include the [changelog](https://dev.sprinklr.com/changelog) every quarter to make it easy for developers to understand new changes/updates to existing endpoints, as well as identify new endpoints that are released.
