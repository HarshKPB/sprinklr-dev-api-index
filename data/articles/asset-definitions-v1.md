# Asset Definitions

Asset definitions include the fields and the information on supported social asset types for different media asset types. It also provides information on the specific method types as not every media asset type is supported by all API methods.



[Digital Asset](https://dev.sprinklr.com/digital-asset)

[Text Asset](https://dev.sprinklr.com/text-asset)

[Link Asset](https://dev.sprinklr.com/link-asset)

[Post Asset](https://dev.sprinklr.com/post-asset)
