# Search

Search can help you quickly find and access all the entities of Sprinklr like Assets, Campaigns, Dashboards, Cases, Macros, Rules and Tasks, thus saving time in locating data that you want to view.

Search APIs supports multiple entity types to perform search on, such as:

`MESSAGE`, `CASE`, `USER`, `OUTBOUND_MESSAGE`, `CAMPAIGN`, `SUB_CAMPAIGN`, `SOCIAL_ASSET`, `TASK`, `AUDIENCE_ACTIVITY`, `PROFILE`

For the results that go beyond the mentioned page size, [Search by Cursor API](https://dev.sprinklr.com/search-by-cursor) is used to fetch the next set of data.
