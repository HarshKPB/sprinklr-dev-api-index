# Comment (Note)

	Comment (i.e. termed as Note in Sprinklr Platform) helps promote engagement between the agents working on the Case. By using Comment APIs, a brand agent sitting on a 3rd party tool can add comments on a case programmatically, which can be used by another agent for reference.

Sprinklr supports APIs that allow adding, reading, updating, and deleting comments. The added advantage is to create notes with attachments such as image, file, or even video.

Supported Entity Types

- MESSAGE

- OUTBOUND_MESSAGE

- CASE

- CAMPAIGN

- PROFILE
