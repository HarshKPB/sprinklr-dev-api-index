# Queues v1

# Queues
 

Find queues within Stream workflow information, and use [Bootstrap](https://dev.sprinklr.com/bootstrap-resources-v1) for configuration information.







| Fields | Type | Description |
| --- | --- | --- |
| clientId | Long | clientId for client queue |
| partnerId | Long | partnerId for partner Queue |
| id | Long | Queue Id |
| name | String | Queue Name |
| description | String | Description of queue |
| delflag | Boolean | Is the queue marked delete |
| modifiedTime | String | Modified time of queue |
| createdTime | String | Creation time of queue |
| ownerUserId | Long | UserId who created the queue |
| queueType | ENUM | INBOUND_MESSAGES |
