# API1.0

#
        API 1.0


API v1 stands for version 1 and is a standard and earliest version available for implementing integrations. Sprinklr offers API v1 endpoints for accessing Sprinklr data. To explore API v1 endpoints, you need to register an app and generate the authorization token. You can refer to [Getting started](https://dev.sprinklr.com/api-key-and-secret-generation) guide for the step-by-step process.

Customers using API v1 can continue to do so until they wish to make a switch. However, we recommend using the latest API v2 version for implementing new integrations. Refer to [API v2](https://dev.sprinklr.com/api2-0) section for more information.
