# Troubleshooting Live Chat Mobile SDK - iOS


This document provides solutions to common issues you might encounter while integrating the Sprinklr Live Chat SDK.

## Issue 1: Status Bar Appearance

Add **"View controller-based status bar appearance"** in your project’s **Info.plist** and set its value to **NO**.

## Issue 2: Live Chat Screen Not Loading (Infinite Loader/Error Screen)

In the **URLs field**, add **"*"** for your application.

Navigation path: Sprinklr Service tab > Listen > Live Chat Care > three dots alongside your Live Chat Application > Edit Live Chat > Application Configuration Screen

Also, reach out to the product team to set the **"enforceSecurity"** flag to **false** for your Live Chat application.

## Issue 3: Live Chat Not Showing with Authenticated User Details

Validate the expected hash for any authenticated user passed inside chat settings.

Navigation path: Options icon alongside your Live Chat Application > Validate User Hash

On the **Validate User Hash** window:


- Enter User ID, Profile Image URL, First Name, Last Name, Phone Number, and Email.

- Click **Copy Generated Hash** and verify it against the hash generated by your system.
