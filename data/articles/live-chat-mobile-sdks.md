# Live Chat Mobile SDK
The **Sprinklr Live Chat Mobile SDK** enables brands to embed real‑time customer support directly into their mobile applications. It provides a customizable chat experience that aligns with your brand’s requirements, supporting both automated bots and live agents.

## Supported Capabilities



- **Integrate Live Chat** into mobile apps for seamless customer support

- **Listen to Events** such as chat session start, agent join, bot handoff, or call initiation

- **Trigger Custom Actions** based on events (for example, analytics logging, UI updates)

- **Customize the Chat Experience** to match brand guidelines and user flows

- **Enable Advanced Interactions** like video calling and co‑browsing

- **Handle Notifications** for ongoing conversations and customer updates
