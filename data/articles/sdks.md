# SDKs

# SDKs

Sprinklr SDKs help developers embed Sprinklr capabilities directly into their own applications and customer experiences.

Use these SDKs to integrate live chat, collect feedback, and build seamless conversational experiences using Sprinklr services.

## Available SDKs

### 1. Live Chat SDK



      Enable real-time conversations between customers and agents within your web or mobile applications.
      Live Chat SDK is a collection of methods for Live Chat extensibility. SDK methods give you complete control over how the Live Chat support works on your website or mobile app. You can define how customers can open and close the chat window, what information must be shown when the chat window opens, and more. Refer to [Live Chat SDK documentation](https://dev.sprinklr.com/live-chat-sdks) for more details.

### 2. Headless Live Chat SDK



      Use the Headless Live Chat SDK to integrate Sprinklr’s chat engine without the default UI components.
      This SDK is designed for developers who want full control over chat rendering and interaction flow. Refer to
      [Headless Live Chat SDK documentation](https://dev.sprinklr.com/headless-live-chat-sdk) for more details.


### 3. CFM Survey Kit SDK



      The CFM Survey Kit SDK enables embedding customer feedback forms and surveys into your applications.
      Use it to trigger in-app surveys in mobile applications. Refer to
      [CFM Survey Kit SDK documentation](https://dev.sprinklr.com/sprinklr-survey-kit-sdk) for more details.
