# CRM User Mapping

#
  CRM User Mapping

 Once you have configured the CRM Connector in Marketplace, for every user who needs access to Sprinklr console within Salesforce must be mapped between the two platforms. This one-to-one mapping associates the Salesforce user with the Sprinklr user, thereby ensuring data governance, compliance and tracking.

The CRM User Mapping APIs facilitates automating creation, fetching, and updating the one-to-one user mapping between Salesforce and Sprinklr user.
