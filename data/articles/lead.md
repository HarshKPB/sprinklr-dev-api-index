#  Lead


	A lead event is an action a /customer(profile) performs along the customer journey. For example, watching a demo or subscribing to the newsletter could be one lead event. Similarly, adding the product to the cart or asking for a free consultation could be another. Once the lead events are created, leads can be created using lead event filters. This allows segregating the customers based on common attributes, which further facilitates personalized marketing.

A lead event comprises of:

- Event's metadata

- Customer's metadata

The end-to-end process workflow for lead APIs:

**Data Collection (Lead Events and Profile Ingestion) ** ==> **Data Segmentation (Lead Creation using Lead Events Filters)** ==> **Outreach (Voice, WhatsApp, Journey, Email etc.)**

### Lead APIs: TOC

- [Create/Update Lead Event](https://dev.sprinklr.com/create-update-lead-event): This API call helps create and update lead events.

- [Create/Update Bulk Lead Events](https://dev.sprinklr.com/create-update-bulk-lead-event): This API call helps create and update lead events in bulk.

- [Create/Update Lead](https://dev.sprinklr.com/create-update-lead): This API call helps create lead based on lead event filters.
