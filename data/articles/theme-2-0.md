# Theme 2.0

#
Theme

A [Listening Theme](https://www.sprinklr.com/help/articles/themes/introduction-to-listening-themes/64637c4b30f12540268faa7f) is a set of custom filters and keywords that can be used to sort Listening Insights data across a pre-built area of focus. Think of a Theme as a lens through which pre-configured topics can be viewed. Themes can be created manually or saved from an existing widget and can contain additional, one-off keywords or combinations of filters to help visualize data without changing what a Topic itself pulls into the Sprinklr platform. Themes are ideal for repeated use and to quickly surface data.

 To save your time from creating a new Listening theme from scratch, you can consider adding a prebuilt theme from the [Theme Library](https://www.sprinklr.com/help/articles/theme-creation-setup/use-theme-library-for-theme-creation/63f7999b9b334f7283b4db13). It contains 5000+ readily available themes based on various categories and different industries.
