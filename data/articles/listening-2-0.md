# Listening 2.0

#
  Listening


Social Listening gives brands visibility and insight into online conversations - across channels, websites, news sources, and more. Various segments in listening include:

### Topics

Topics are queries built by multiple keywords or keyword lists that let you bring in conversations or messages not sent directly to your brand.

**Related Knowledge Base Category:** **[Listening Topics](https://www.sprinklr.com/help/articles/topics/introduction-to-listening-topics/6405ee7b7a695d65a1606b79)**

### Themes

A Listening Theme is a set of custom filters and keywords that can be used to sort Listening Insights data across a pre-built area of focus.

**Related Knowledge Base Category:**  **[Listening Themes](https://www.sprinklr.com/help/articles/themes/introduction-to-listening-themes/64637c4b30f12540268faa7f)**

### Keyword Lists

In Listening, Keyword Lists are a single list of words or phrases that can be used in multiple query builds. You can create these Keyword Lists if there are a group of words that you want to filter out or include for multiple queries.

**Related Knowledge Base Article:**  **[Listening: Keyword Lists](https://www.sprinklr.com/help/articles/keyword-lists/introduction-to-keyword-lists/646384b430f12540268faaa1)**

### Listening Topics

You can sort Listening Topics by groups with the help of Group By option, to help control, organize and display a limited set of Listening Topics. You can also filter your topics by single or multiple filters.

**Related Knowledge Base Article:**  **[Group By and Filter Listening Topics](https://www.sprinklr.com/help/articles/topic-management/group-by-and-filter-listening-topics/640ac9dd2680c35a78bb2021)**
