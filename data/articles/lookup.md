#  Lookup



The Lookup API is a versatile tool designed to retrieve details of various entities based on specified lookup types. For instance, using the `FACEBOOK_PLACES_LOOKUP` type allows you to obtain unique location IDs for different places on Instagram.
This API supports multiple lookup types, including `ACCOUNT_ID, USER_ID, CASE_ID, CUSTOM_FIELD, SMART_SEGMENT_ID, and ASSIGNMENT_SKILL.` By specifying the appropriate lookup type and IDs within the keys parameter, you can efficiently find the necessary details for different entities.
