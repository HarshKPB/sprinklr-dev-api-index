# CFM Survey Kit SDK for Flutter

You can integrate Sprinklr Survey Kit into your brand's Flutter mobile application to collect customer feedback through in-app surveys and intercepts. Sprinklr offers a comprehensive Survey Kit Mobile SDK built on native iOS and Android SDKs to enable this functionality.

**Dev Notes: **To learn more, see [key concepts](https://dev.sprinklr.com/sprinklr-survey-kit-sdk).

## Survey Kit SDK Version

**Current Version**: 0.1.0

## Compatibility Requirements

Ensure your development environment meets the following minimum version requirements to integrate and use the Sprinklr Survey Kit SDK successfully.






































| Framework or Platform | Version |
| --- | --- |
| Flutter | 3.16.0 and above |
| Android Gradle Plugin (AGP) | 8.1.1 or later |
| Gradle | 8.0 or later |
| Java (JDK) | 17 or later |
| Minimum Android SDK Version | 24 |
| Ruby | 3.2.1 or later |
| CocoaPods | 1.14.0 or later |
| iOS | 15.0 or later |

**Dev Note: **Using earlier versions of these components may result in build failures or unexpected behavior. It is recommended to use the latest stable versions supported by your development environment and Android Studio.

## Key Features


- **Event-Driven Architecture:** Real-time event and log callbacks

- **Session Tracking:** Automatic user session management

- **Intercept Management:** Evaluate and display survey intercepts with targeting rules

- **User Interaction Tracking:** Track button clicks and page visits

## Integration Steps


- [Install Survey Kit SDK](https://dev.sprinklr.com/install-sprinklr-survey-kit-sdk-for-flutter): Add the Sprinklr Survey Kit SDK package to your Flutter app, install it, and complete the setup to start using the SDK in your project.

- [Initialize Survey Kit](https://dev.sprinklr.com/initialize-sprinklr-survey-kit-sdk-for-flutter): Use the `initializeProject` method to initialize the Sprinklr Survey Kit in your Flutter app with your App ID, environment, and device configuration.

- [Integrate SDK Methods](https://dev.sprinklr.com/sprinklr-survey-kit-sdk-methods-for-flutter): Integrate SDK methods such as display methods to show surveys to users based on evaluation results and targeting rules. Register user interactions such as page visits and button clicks to trigger surveys at appropriate moments.

## Advanced Configuration

Once Survey Kit is integrated, you can enhance the survey experience by:


- [Event Monitoring](https://dev.sprinklr.com/survey-events-listener-for-flutter): Set up event handlers to track survey lifecycle events including initialization, evaluation, display, and completion.

- [Log Management](https://dev.sprinklr.com/enable-survey-events-logging-for-flutter): Configure log handlers for debugging and monitoring SDK operations with customizable log levels.
