# Configure Live Chat App Settings

## Configure Settings

You can edit the automatically generated settings according to your requirements. The following table lists the Live Chat settings and their descriptions:

| Setting | Type | Description | Possible values |
| --- | --- | --- | --- |
| appId | string | The application ID provided in the generated code. This ID is a unique identifier of your Live Chat app and cannot be changed. | Automatically generated |
| locale | string | The BCP 47 compliant language code. For example, you can pass "ar" for Arabic or "en" for English. This language is used in the Live Chat application.  Note: You can specify only those languages that you configured in the Default language and Additional language screens of the Live Chat builder. | To view the list of supported languages, see . |
| user | {        id: string;        hash: string;        email?: string;        firstName?: string;        lastName?: string;        profileImageUrl?: string;        phoneNo?: string;    } | The user details of the customer are used for authenticating the customer. |  |
| customUser | customUser?: {    [key: string]: any;    }; | You can define a custom user. You can specify the details of the custom user according to your requirements. |  |
| clientContext | StringTMap<string[]> | The custom fields or metadata associated with all the new conversations started by the user. This custom field will be reflected at a case level. To know more about custom fields, see . |  |
| userContext | StringTMap<string[]> | Custom fields or metadata for the current user. This value will be reflected at the user profile level. |  |
| autoTrigger | boolean \| number; | Defines whether a conversation will be automatically triggered or not. | true: If set to true, the chat box shows up instantly. false: If set to false, the chat box does not show up until triggered by some other condition. number: The time in seconds after which the chat window must come up. For example, if it is set to 10, the chat window will open after 10 seconds. |
| disableAttachment | boolean; | This is used to disable or enable the attachment functionality within the Live Chat app. | true: If set to true, it disables the attachment functionality. false: If set to false, it enables the attachment functionality. |
| enableClose | boolean; | This setting is used to enable or disable the close icon. | true: If set to true, the close icon is shown on all the pages including desktop mode. false: If set to false, the close icon is not shown on all the pages. |
| device | 'MOBILE' \| 'DESKTOP'; | This setting is used to set the device type on which you want to set up the Live Chat app. | MOBILE: Use this to set up Live Chat on mobile devices. DESKTOP: Use this to set up Live Chat on desktop devices. |
| variant | 'WIDGET' \| 'PAGE'; | This setting is used to define whether you want the Live Chat app to render on a page or in a full page. | WIDGET: The Live Chat app is rendered in the corner of a page. PAGE: The Live Chat app is rendered in full page. |
| scope | 'CONVERSATION' \| 'ALL'; | Choose to render only conversation pages or widget with all pages. | CONVERSATION: This only renders the conversation pages. ALL: This renders both the home screen and conversation pages. Default value is ALL. |
| landingScreen | 'NEW_CONVERSATION' \| 'LAST_CONVERSATION' \| string; // Here string represents "CONVERSATION_{convId}",  "CASE_{caseId}" or "ERROR_{statusCode}" | Choose the first page that opens in the Live Chat home screen when it is opened. | NEW_CONVERSATION: Opens a new conversation. LAST_CONVERSATION: Opens the last conversation if any. Otherwise, opens a new conversation. ERROR_{statusCode}: Opens /statusCode pages as landingScreen. Default: Opens the default page of the home screen. |
| disableHeader | boolean | Defines whether to disable or enable app header in the CONVERSATION scope only. | true: Disable app headers in the CONVERSATION scope. false: Enable app headers in the CONVERSATION scope. |
| container | string | CSS Selector of the container element in which you want to render PAGE_VARIANT. |  |
| sessionOrigin | string | Origin to where subdomain chat persistence is configured. |  |
| disableAnalytics | boolean | Disables app header in CONVERSATION scope only. |  |
