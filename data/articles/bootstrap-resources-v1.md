# Bootstrap Resources V1

#
Bootstrap Resources V1


	Bootstrap resources is a one-stop API repository for extracting metadata of objects configured within the user environment. The different resource types that can be extracted using this API, includes:

****

****

| Resource Type | definition |
| --- | --- |
| Partner Accounts | Returns the list of all active accounts in the partner environment |
| Partner Campaigns | Returns the list of global campaigns in the partner environment |
| Partner Account Groups | Returns the list of all existing account groups |
| Partner Users | Returns the list of all users in the partner environment |
| PARTNER_USERS for Given Client Id | Returns the list of all local users in the client environment |
| Clients | Returns all the clients within Sprinklr Partner environment |
| Client URL Shorteners | Returns the list of client URL shorteners |
| Inbound Custom Fields | Returns the list of inbound custom properties |
| Outbound Custom Fields | Returns the list of outbound custom properties |
| PROFILE_CUSTOM_FIELDS | Returns the list of profile custom properties |
| MEDIA_ASSET_CUSTOM_FIELDS | Returns the list of asset custom properties |
| ACCOUNT_CUSTOM_FIELDS | Returns the list of account custom properties |
| UM_STATUSES | Returns the list of account custom properties |
| UM_PRIORITIES | Returns the list of priorities |
| ACCESSIBLE_USERS | Returns the user profile information for users who have access to the workspace. |
| APPROVAL_PATHS | Returns the approval paths |
| PARTNER_QUEUES/CLIENT_QUEUES | Returns the queues in the partner or client environment |
| PARTNER_PROFILE_LISTS/CLIENT_PROFILE_LISTS | Partner: Returns the profile lists in the partner (global) environmentClient: Returns the profile lists in client (workspace) environment |
| MACROS | In the UI, macros can be used to execute multiple actions on a message, asset, or profile with a single click, creating workflow efficiencies. This API returns a list of available macros |
| PERMISSIONS | Permissions regulate user authorization via the UI. This API returns the available permission combinations per platform area |
| USER_GROUPS | Returns the list of user group |
