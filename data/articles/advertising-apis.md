#  Advertising APIs



    The Ads Publishing API provides a unified, channel-agnostic interface for creating, managing, and publishing advertising campaigns across multiple social media platforms. It abstracts the native API differences of Facebook, Instagram, LinkedIn, and X (formerly Twitter), allowing Sprinklr’s Advertising Platform to orchestrate cross-channel ad operations seamlessly.



### Key Capabilities:



-
      **Campaign Lifecycle Management**


  - Create, update, and report campaigns across channels.

  - Retrieve campaign status, performance metrics, and diagnostics.



-
  **Ad Set / Ad Group Operations**


  - Define ad sets (or ad groups) with channel-specific targeting parameters (e.g., audiences, placements, bid strategies).

  - Configure budgets, schedules, optimization goals, and pacing.


-
  **Targeting & Audience Handling**


  - Specify demographic, interest, and behavioral targeting through a common schema.

  - Leverage custom and lookalike audiences consistently across platforms.


-
  **Budgeting & Bidding**


  - Allocate daily or lifetime budgets at campaign or ad set level.

  - Select and apply bidding strategies.


-
  **Scheduling & Delivery Controls**


  - Set campaign/creative start and end dates, dayparting, and frequency caps.

  - Monitor delivery pacing and enforce spend limits.


-
  **Error Handling & Validation**


  - Pre-flight validation of requests against each channel’s schema.

  - Unified error codes and messages, with detailed channel-specific diagnostics for troubleshooting.


-
  **Reporting & Insights**


  - Fetch real-time campaign performance metrics (impressions, clicks, spend, conversions).

  - Normalize and map metrics to Sprinklr’s analytics data model.
