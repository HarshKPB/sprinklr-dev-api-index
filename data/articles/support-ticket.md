# Support Ticket

#
Support Ticket



 BETA! This feature belongs to the Sprinklr Care Lite Product. You can create support tickets and even fetch the custom fields for an existing support case using these APIs. In detail, you can further enhance the ticket by defining additional custom fields that define the problem and your business use case.

Once the case is created, it is sent to Sprinklr Care Lite and a ticket is automatically created. You can also fetch the defined custom fields attributes of the existing case.

### Support Ticket APIs

- [Create Support Ticket](https://dev.sprinklr.com/create-support-ticket): Using this API, you can create support tickets and register cases in Sprinklr Care Lite.

- [Fetch Support Case Custom Fields](https://dev.sprinklr.com/fetch-support-case-custom-fields): You can use this API for fetching the custom fields for an existing support case.
