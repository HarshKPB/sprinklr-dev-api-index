# Keyword List


In Listening, [Keyword Lists](https://www.sprinklr.com/help/articles/entities/introduction-to-keyword-lists/64634db78ea3c9635cf3673d) are a single list of words or phrases that can be used in multiple query builds. You can create these Keyword Lists if there are a group of words that you want to filter out or include for multiple queries. Keyword Lists is used to sort social listening and pull out relevant queries with a list of words or phrases.  The Keyword Lists you create in Listening Insights will automatically sync with Settings Keyword Lists. This means that any Keyword Lists you create or edit in Listening Insights will update in Settings Keyword Lists and vice versa.

Synced Keyword Lists help ensure that updates are standard throughout your environment and prevent a duplication of efforts, allowing you to update Keyword Lists with a single update.  If any Listening Queries uses Keyword Lists, updates made by users who have permission to edit Keyword Lists from Admin Settings will reflect in Query using that Keyword List.
