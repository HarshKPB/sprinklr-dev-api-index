# Troubleshooting LC Mobile SDK - Flutter

# Troubleshooting - Flutter

## Issue 1: Live Chat not showing up while passing authenticated user details

Check the expected hash for any authenticated user passed inside chat settings.

Hover over the Options icon alongside your Live Chat Application and select **Validate User Hash**.

On the Validate User Hash window, enter User ID, Profile Image URL, First Name, Last Name, Phone Number and Email. Click **Copy Generated Hash** and verify it with the hash generated by you.

## Issue 2: Check if correct FCM Server key is being used for push notifications

Use the following curl with your FCM server key and registration device token, to check if the FCM Server key is correct or not:




curl --location 'https://fcm.googleapis.com/fcm/send' \
--header 'Content-Type: application/json' \
--header 'Authorization: key=' \
--data '{
    "to": "",
    "data": {
        "title": "Title", //Title of the push notification
        "message": "New Message" //Message of the push notification
    }
}'






## Issue 3: More than one file was found with OS independent path

Add the following lines to your app's `build.gradle` file:




android {
    packagingOptions {
        pickFirst 'lib/armeabi-v7a/*.so'
        pickFirst 'lib/arm64-v8a/*.so'
        pickFirst 'lib/x86/*.so'
        pickFirst 'lib/x86_64/*.so'
        exclude 'META-INF/LICENSE'
    }
}






## Issue 4: Gestures being registered on both LiveChat SDK and Flutter application

**Dev Notes: **This issue might happen on some older Flutter versions.

To override the gesture responder chain in `MessengerViewController` to skip `FlutterViewController`, preventing Flutter from becoming the touch responder when Live Chat is open, configure `SPRMessengerConfig` as follows:




SPRMessengerConfig messengerConfig = SPRMessengerConfig(
  // Other configuration options
  overrideMessengerViewsResponderChain: true,
);
SPRMessenger().takeOff(config: messengerConfig);






Alternatively, set the flag directly when starting Live Chat:




SPRMessenger().startApplication(overrideMessengerViewsResponderChain: true);






By setting `overrideMessengerViewsResponderChain` to true, gesture events are only registered on the intended screen, preventing conflicts between Live Chat and Flutter.

## Issue 5: Android Build Failure When minifyEnabled is Set to True

You are encountering an Android build failure when `minifyEnabled` is set to true.

**Solution:** Add the following rules to your `proguard-rules.pro` file:




-keep class com.facebook.react.devsupport.** { *; }
# If co-browsing is enabled:
-keep class io.cobrowse.** { *; }
