# Asset Group

#
Asset Group

The asset group refers to the entities in Sprinklr that can be grouped. For example, An [Account Group](https://www.sprinklr.com/help/articles/account/add-an-account-group/6467ccf730f12540268fb93b) is a grouping of multiple accounts that can be created by individually selecting accounts to add (static) or based on a property or properties (dynamic). Another example would be the [User Group](https://www.sprinklr.com/help/articles/sprinklr-service-glossary/user-groups/64090b5a7517d84a3aaf3993), which comprises multiple users at the Workspace level.

The Asset Group APIs help you in performing CRUD functions programmatically. You can create, read, update and delete asset groups.

Supported Assets Groups:

- Account Groups

- User Groups

- Topic Groups

- Workspace Groups
