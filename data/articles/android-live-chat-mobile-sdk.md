## Live Chat SDK Version

**Current Release:** 14.0.2

**Supported Versions:** Starting August 2025, Live Chat SDK versions 7.0.0 and above are supported.

  Starting August 2025, Live Chat SDK 6.2.0 and lower versions will be deprecated.
  We recommend upgrading to versions 7.0.0 or higher for continued support.

## Compatibility

Live Chat SDK supports Android devices with a 16 KB memory page size.


























| Framework or Platform | Version |
| --- | --- |
| React Native | Version ≥ 0.70.0 and Version ≤ 0.80.1 |
| Android | Minimum SDK version ≥ 24 |
| iOS | Minimum iOS version ≥ 15.1 |
| Gradle | No restrictions (depends on the React Native version used) |
| Xcode | No restrictions (depends on the React Native version used) |

## App Size Impact

The increase in app size after integrating the Live Chat SDK depends on the platform and framework.
Integrating the Live Chat SDK will increase your app size approximately by:


- Android: ~6MB

The final size may vary based on customizations of peer dependencies.
