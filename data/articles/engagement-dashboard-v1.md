# Engagement Dashboard v1

#   Engagement Dashboard


	Engagement Dashboards allow you to create customized workflow dashboards in which messages can be viewed, acted upon, engaged with, assigned, and more. From the Engagement Dashboards, your team can view and take action on messages in columns custom configured to display the content they need to be able to see and act upon.
