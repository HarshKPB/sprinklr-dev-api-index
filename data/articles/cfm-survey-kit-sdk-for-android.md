# CFM Survey Kit SDK for Android

# CFM Survey Kit SDK for Android

You can integrate Customer Feedback Management (CFM) in your Android app to display surveys to users based on certain conditions (intercepts).

**Dev Notes: **To learn more, see [key concepts](https://dev.sprinklr.com/sprinklr-survey-kit-sdk).

## Compatibility Requirements for Android

Ensure your development environment meets the following minimum version requirements to integrate and use the Sprinklr Survey Kit SDK successfully.

- **Android Gradle Plugin (AGP)** 8.1.1 or later

- **Gradle:** 8.0 or later

- **Java (JDK):** 17 or later

- **Minimum SDK Version:** 24

**Dev Note: **Using earlier versions of these components may result in build failures or unexpected behavior. It is recommended to use the latest stable versions supported by your development environment and Android Studio.

## Advanced Configuration

Once the SDK is integrated, you can enhance the user experience further by enabling advanced configurations:

- [Listen to SDK Events](https://dev.sprinklr.com/survey-events-listener-for-android): Listen to a comprehensive set of events related to initialization, page visits, button clicks, intercept evaluations, and more, to gain real-time visibility into the lifecycle of intercepts, surveys, and user sessions.

- [Enable Survey Events Logging](https://dev.sprinklr.com/enable-survey-events-logging-for-android): Enable logging to capture events at various levels based on your requirements. You can log information such as critical errors, warnings, and high-traffic events. This flexible logging system enhances troubleshooting efficiency, helping you monitor app behavior and resolve issues quickly.
