#
  Integration Blueprints

In these tutorials we will cover the basics of connecting to the Sprinklr APIs as well as some common use cases for extracting data.

		 **Getting Started**
In this guide, you’ll learn how to request Sprinklr API key and step-by-step instructions of the authentication process to generate an access token, which you will use to make an HTTP GET request for the Clients in your Partner Environment.

**Care Cloud to 3rd party CRM (Care) Integration**
 Enterprise customers use Sprinklr Social Care to provide support to their customers on various social channels such as Facebook, LinkedIn, Twitter etc. However, some Enterprise customers use 3rd party CRM tools such as Salesforce, MS Dynamics, SAP C4C, ServiceNow, Oracle RightNow for email, web and phone support.


	**Sprinklr Reporting Widget Tutorial**

In this guide, you’ll learn how to convert Sprinklr UI Widget into API payload to easily extract the reporting data, which is helpful in making future company strategy and decisions.
