# Topic Backfill 2.0

#
  Topic Backfill

Topic Backfill Request in Social Listening allows you to access historic data quickly. You can populate new topics with historic data, providing instant access and insight into past conversations.

**Note:** Please reach out to your Success Manager to get the Backfill API's enabled for your environment.

Key capabilities of Topic Backfill Request include:

-  Search all social channels and web-sources quickly to see volumes, trends of mentions, and relevant insights 

- Fine-tune Listening insight topics, queries, and themes 

- Review all historical data for relevant mentions in the past 

- Max number of mentions per backfill is capped to 5 million per trigger. 

Using Sprinklr Backfill APIs you can Create, Read, Accept and, Cancel backfill programmatically.

**Dev Notes: **Backfill Sources available via API are:

`REVIEWS,PRINT,FORUMS,FACEBOOK,TV,REDDIT,QUORA,YOUTUBE,WORDPRESS,BLOGS,VK,NEWS,RADIO,TWITTER`
