# Developer Portal Registration

#
Developer Portal Registration

Developer portal registration is mandatory and the first step toward accessing Sprinklr APIs.

**Link: **** [Developer Account Registration](https://dev.sprinklr.com/create)**

Once you click on the registration link, you will be redirected to fill out a form. The form fields include:

	****
	****
	****







****

| Field | Description | Required/Optional |
| --- | --- | --- |
| First Name | Refers to your first name | Required |
| Last Name | Refers to your last name | Required |
| Company | Refers to your company's name | Optional |
| Country | Refers to the country you are registering from | Optional |
| Password | Refers to the password for securing your developer account | Required |

Once you fill all the required details, hit the register button. Next, you will receive a confirmation email which when clicked upon will enable your developer portal account. Once confirmed, you can log in to the Sprinklr Developer Account to create API keys.

**Note: **

 If you do not receive the confirmation message within a few minutes of signing up, please check your Spam folder just in case the confirmation email got delivered there instead of your inbox. If so, select the confirmation message and click "Not Spam", which will allow future messages to get through.

If it's not present in the Spam folder as well then please check with your IT team/mail admins to see if they have any rule to reject emails sent via AWS SES service. You might additionally have to whitelist AWS SES service to send you emails on behalf of api@psprinklr.com.
