# Engagement Dashboard

#
Engagement Dashboard


Stream API allows the user to fetch the data flowing through a particular column configured in an Engagement dashboard or care console or agent console. This can be an outbound or inbound column. Once the column is created in Sprinklr, it has a unique stream ID assigned to it which can be used in the API call to extract data.
