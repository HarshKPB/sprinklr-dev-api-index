# Changelog

#
Changelog

Sprinklr API changelog provides every minute change details of APIs to ensure that API developer-consumers are aware of any upgrades or changes in the endpoints. The changes to an API are directly related to business as the end customer & user experience may be affected if an API is being used in an application product suddenly becomes inaccessible.

## Why APIs Changelog

Here are are usually 4 types of changes:

- API Endpoint Enhancement

- New API Endpoints

- API deprecation

- Change in Terms of Service

The largest section of API changes is linked with Sprinklr features and native deprecations as Sprinklr supports 35+ Modern Channels that include social and messaging apps. Usually, application features are backed by APIs, and any changes in the features may lead to changes in the API which can be seen instantly on the API Changelog.

New API endpoints are exposed to provide developers an efficient path for customer implementations and integrations.

Terms of service-related changes happen less often but are very relevant because they are usually related to usage limits. So that can affect your API client implementation.
