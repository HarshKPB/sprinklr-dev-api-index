# Webhook Replay and Retrieve

#
Webhook Replay and Retrieve


 Webhook R&R API provides the functionality to retrieve and replay the stream of webhooks for a given time duration. The use cases covered by webhook replay and retrieve include:

- [Webhook Replay](https://dev.sprinklr.com/webhook-replay#init): To replay the stream of webhooks for a given time duration

- [Cursor API](https://dev.sprinklr.com/webhook-replay#stream): To fetch and replay the next set of data
[Retrieve Failed Webhooks](https://dev.sprinklr.com/retrieve-failed-webhook-events): The API call will help you retrieve failed webhooks for a subscription in a given time.
