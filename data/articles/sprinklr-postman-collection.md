# Sprinklr Postman Collection

#
  Sprinklr Postman Collection

Postman is a tool to help test and develop APIs. To make it more convenient for developers who are integrating with the Sprinklr APIs, we've developed a Postman collection that contains the full set of APIs.

[Postman collection for Sprinklr APIs](https://www.postman.com/sprinklr-api/sprinklr-public-api-collections/overview)
