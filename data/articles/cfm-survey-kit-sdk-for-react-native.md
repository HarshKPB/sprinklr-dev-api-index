# CFM Survey Kit SDK for React Native

You can integrate Sprinklr Survey Kit into your brand's React Native mobile application to collect customer feedback through in-app surveys and intercepts. Sprinklr offers a comprehensive Survey Kit Mobile SDK built on native iOS and Android SDKs to enable this functionality with full TypeScript support.

**Dev Notes: **To learn more, see [key concepts](https://dev.sprinklr.com/sprinklr-survey-kit-sdk).

## Survey Kit SDK Version

**Current Version**: 0.1.0

## Compatibility Requirements

Ensure your development environment meets the following minimum version requirements to integrate and use the Sprinklr Survey Kit SDK successfully.






























| Framework or Platform | Version |
| --- | --- |
| React Native | ≥ 0.78.0 |
| React | ≥ 19.0.0 |
| Android | Minimum SDK version ≥ 24 (Android 7.0) |
| iOS | Minimum iOS version ≥ 15.1 |
| CocoaPods | ≥ 1.15.0 |
| Swift | ≥ 5.0 |

**Dev Note: **Using earlier versions of these components may result in build failures or unexpected behavior. It is recommended to use the latest stable versions supported by your development environment and Android Studio.

## Key Features


- **TypeScript Support:** Complete type definitions included

- **New Architecture Ready:** Supports React Native's new architecture (Turbo Modules)

- **Event-Driven Architecture:** Real-time event and log callbacks

- **Session Tracking:** Automatic user session management

- **Intercept Management:** Evaluate and display survey intercepts with targeting rules

- **User Interaction Tracking:** Track button clicks and page visits

## Integration Steps


- [Install Survey Kit SDK](https://dev.sprinklr.com/install-sprinklr-survey-kit-sdk-for-react-native):
    Configure `.npmrc` with Sprinklr registry authentication to access the restricted package, install the Survey Kit SDK package in your React Native project using npm or yarn, and complete iOS setup by installing CocoaPods dependencies for native integration.


- [Initialize Survey Kit](https://dev.sprinklr.com/initialize-sprinklr-survey-kit-sdk-for-react-native): Use the `initializeProject` method to initialize the Sprinklr Survey Kit in your React Native app with your App ID, environment, and device configuration.

- [Integrate SDK Methods](https://dev.sprinklr.com/sprinklr-survey-kit-sdk-methods-for-react-native): Integrate SDK methods such as display methods to show surveys to users based on evaluation results and targeting rules. Register user interactions such as page visits and button clicks to trigger surveys at appropriate moments.

## Advanced Configuration

Once Survey Kit is integrated, you can enhance the survey experience by:


- [Event Monitoring](https://dev.sprinklr.com/survey-events-listener-for-react-native): Set up event handlers to track survey lifecycle events including initialization, evaluation, display, and completion.

- [Log Management](https://dev.sprinklr.com/enable-survey-events-logging-for-react-native): Configure log handlers for debugging and monitoring SDK operations with customizable log levels.
