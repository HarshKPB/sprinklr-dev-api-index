# Headless Live Chat SDK

Live Chat enables seamless integration of chat support directly into your websites. Sprinklr provides a **headless Live Chat SDK**, a versatile and flexible solution that delivers all the essential infrastructure and logic needed for Live Chat functionality.

This empowers brands to design fully custom user interfaces while leveraging the complete suite of Live Chat features. With this SDK, developers can effortlessly implement Live Chat capabilities and tailor the UI to perfectly align with their brand’s aesthetics and specific requirements.

## Key Features

The headless Live Chat SDK offers the following key features:


-
    **UI Flexibility:** The SDK does not include a predefined UI, giving brands the flexibility to design their own chat interfaces.


-
    **Infrastructure and Logic:** All backend infrastructure and chat logic are handled by the SDK, simplifying the implementation process.


-
    **Ease of Implementation:** The SDK is designed to be straightforward to integrate into existing systems.


-
    **Command Set:** A comprehensive set of functions and commands to manage chat operations.
