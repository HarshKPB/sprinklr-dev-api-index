# Custom Entity

#  
Custom Entity

 

Sprinklr's Custom Entity helps your teams to programmatically define the data object, save, and utilize external system data in Sprinklr for unified analytics, customer 360° view, profile enrichment etc.

Custom entities are objects you create to store information specific to your company or industry and are flexible enough to define and update as needed using the Custom entity Definition APIs. Once the Custom entities are defined, you can use the create, update, and read APIs to push, update or read the existing custom entity data. Once the custom entity data is pushed, the same can be viewed in the Reporting widget by using Data source = Custom Entity.

**Dev Notes: **Kindly note that the feature needs to be enabled in the customer's instance before you can call the custom entity APIs. You can reach out to your success manager for the enablement.
